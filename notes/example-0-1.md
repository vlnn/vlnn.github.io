Let **1** denote a set with one element. (It does not matter what this element is called.) Then **1** has the following property:

for all sets **X**, there exists a unique map from **X** to **1**. 

*(In this context, the words ‘map’, ‘mapping’ and ‘function’ all mean the same thing.)*

Indeed, let ***X*** be a set. There *exists* a map ***X* → 1,** because we can define *f* :
***X* → 1** by taking *f* (*x*) to be the single element of **1** for each *x* **∈ *X***. This is the
*unique* map ***X* → 1**, because there is no choice in the matter: any map ***X* → 1**
must send each element of ***X*** to the single element of **1**.
