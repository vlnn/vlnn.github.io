A language is homoiconic if its code is represented as a data structure native to the language, so a program can be manipulated as data using the language itself (so [Lisp](lisp.md) is homoiconic, and Python is not, even though it has `ast`  lib).

But "[Homoiconicity isn’t the point](http://calculist.org/blog/2012/04/17/homoiconicity-isnt-the-point/)" states that 
> [!quote]
> What makes Lisp’s syntax powerful is not the fact that it can be represented as a data structure, it’s that **it’s possible to *[read* it](reading-code.md) without </em>parsing</em>**.
