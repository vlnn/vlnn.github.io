Plain and flat todo-list written in the order of ideation.

Main idea is to use a question *What do I want to do before I do x?* repeatedly to chain the tasks into a work sequence.
Second main idea is that by default every item is not ***done*** after work, but rather ***worked on***.

Underlying rule is so called little-and-often (I would call it [Intermittent work](intermittent-work.md)**)**
