I'm using [koreader](https://koreader) on couple Kobo e-ink readers. Main features of my setup:

1. synchronization of bookshelves via [kosyncthing+](https://github.com/d0nizam/kosyncthing_plus.koplugin)
2. the host of dictionaries, starting with [Webster's Revised Unabridged (1913)](https://github.com/cmod/websters-1913), as I was influenced by [this article.](http://jsomers.net/blog/dictionary)
3. Alegreya as a main font to use (I liked WP Wesker Narrow, but it [doesnt work with Cyrillic,](wp-wesker-narrow-font-cyrillic-issue.md) and it's too much of work to switch fonts all the time)
4. The reading progress is also sync'ed between the devices with [koreader plugin](https://github.com/koreader/koreader/wiki/Progress-sync)
