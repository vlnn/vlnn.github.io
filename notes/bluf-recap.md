* [BLUF](bluf.md) (start): State the conclusion, answer, or request in the first sentence, including the main action.
* Body (middle): Add brief context, reasons, and supporting facts.
* Recap (end): Restate the opening line in 1–3 bullets, split into action items and owners if there are several.

So, unlike the [Uneven U,](uneven-u-writing-method.md) this method traces an **Even U**: it begins and ends with the same statement.
